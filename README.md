# Pet Shelter Management System

## About the Project
A simple Pet Shelter Management System developed as an academic project. It manages available pets, adoption processes, and adoption records.

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- HTML
- CSS

## Features
- View available pets
- Adopt a pet
- Store adoption records in a text file
- View adoption history
- Add new pets
- Support for Dogs, Cats, and Birds

## OOP Concepts
- Classes and Objects
- Inheritance
- Encapsulation
- Abstraction
- Polymorphism
- Virtual Functions

## Project Structure
- C++: Backend implementation
- Frontend: HTML/CSS interface prototype
- adoptions.txt: Adoption records
